# Лабораторная работа 3Б — Справочник пользователей с REST API

## Тема
Отображение данных из публичного REST API, фильтрация на клиенте, обработка ошибок.

## Способ запуска

1. Открыть файл `index.html` в браузере (двойной клик или `open index.html`).
2. Серверная часть не требуется. Интернет-соединение необходимо для обращения к jsonplaceholder.typicode.com.

## Реализованные функции

- **GET-запрос:** кнопка «Загрузить пользователей» отправляет `fetch` на `https://jsonplaceholder.typicode.com/users`, проверяет `response.ok`, парсит JSON и выводит имя, email и город каждого из 10 пользователей через DOM (`createElement` + `textContent`).
- **Поиск по имени:** поле ввода фильтрует уже загруженный список в памяти, без HTTP-запроса, регистронезависимо. При отсутствии совпадений — «Пользователи не найдены».
- **Публикации пользователя:** кнопка «Показать публикации» в карточке каждого пользователя отправляет `GET /posts?userId=ID`, выводит заголовки и тексты первых трёх публикаций в отдельной области.
- **Валидация и состояния:** во время загрузки кнопки блокируются (`disabled`), выводится сообщение «Загрузка...». Обработка `try/catch/finally`, сообщение об ошибке при HTTP-ошибках и сетевых сбоях, кнопка снова активируется в `finally`.

## Результаты проверки

- (а) «Загрузить пользователей» → 10 записей с именем, email и городом. ✔
- (б) Ввод «Leanne» → остаётся одна запись. ✔
- (в) Ввод неизвестного имени → «Пользователи не найдены». ✔
- (г) «Показать публикации» → заголовки и тексты первых 3 публикаций. ✔
- (д) Подмена `/users` на `/userz` → 404 → сообщение об ошибке, повторная попытка работает. ✔
