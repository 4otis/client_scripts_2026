# Лабораторная работа 3 — Асинхронный JavaScript и REST API

## Тема
Доска публикаций. Работа с `fetch`, `async/await`, JSON и REST API.

## Способ запуска

1. Открыть файл `index.html` в браузере (двойной клик или `open index.html`).
2. Серверная часть не требуется.

## Реализованные функции

- **GET-запрос:** кнопка «Загрузить публикации» отправляет `fetch` на `jsonplaceholder.typicode.com/posts?_limit=5`, проверяет `response.ok`, парсит JSON и выводит 5 постов через DOM (`createElement` + `textContent`).
- **POST-запрос:** форма с полями «Заголовок» и «Текст» отправляет `{title, body, userId: 1}` методом POST с заголовком `Content-Type: application/json`. Выводит заголовок и ID из ответа.
- **Валидация:** пустые поля или поля из одних пробелов отклоняются с сообщением об ошибке, запрос не отправляется.
- **Состояния и ошибки:** во время запроса кнопки блокируются (`disabled`), выводится сообщение «Загрузка...» / «Отправка...». Обработка `try/catch/finally`, сообщение об ошибке при 404 и сетевых сбоях, кнопка снова активируется в `finally`.

## Результаты проверки

- (а) «Загрузить публикации» → 5 записей с заголовками и текстом. ✔
- (б) Пустые поля / одни пробелы → ошибка, запрос не отправляется. ✔
- (в) Корректный POST → HTTP 201, заголовок + ID из ответа + сообщение об успехе. ✔
- (г) Подмена адреса на `/postz` → 404 → сообщение об ошибке, кнопка снова активна. ✔
